# Mephisto

Deutsch für Klinik und Leben: an installable study app (PWA) for a doctor moving to Germany.
Fachsprachprüfung, Goethe/telc B2 and telc Medizin practice, daily-life German, literature and film.

Open **https://mephisto-deutsch.github.io/Mephisto/** in Safari (iPhone: Share → Add to Home Screen)
or Chrome (Android: menu → Install app). Works offline after the first visit.

Progress is stored only on the device (localStorage). Move it between devices with Ich → Daten → Backup.

Build 12.9.0-c23fe06997. Fonts: Fraunces, Source Serif 4, Source Sans 3, JetBrains Mono, UnifrakturMaguntia,
